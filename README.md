# Pokemon-Storage-Database
Theoretical database structure for the pokemon storage system
# ERD
The ERD for this database can be found in the file "Pokemon Storage.png"
![Png of the Schema](https://github.com/JamesZheng109/Pokemon-Storage-Database/blob/main/Pokemon%20Storage.png)
# Schema and Data
In the file "Schema and Data" you will find a jupyter notebook that webscrapes data from [Pokémon Database](https://pokemondb.net) for the following: 
- List of abilities
- List of held items
- List of natures
- List of pokemon including:
  - name
  - type
  - type 2

This information can be exported in the following file formats:
- .sql file
- .csv file
- .txt file
